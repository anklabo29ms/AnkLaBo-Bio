# AnkLaBo-Bio ⚡
> Personal aesthetic bio link website inspired by **guns.lol** & **zyo.lol**, designed exclusively for **AnkLaBo**.

## 🌟 Features
- 🚀 **Click-to-enter Gatekeeper**: Aesthetic dark overlay with smooth transitions and audio autoplay unlock.
- 💎 **Glassmorphism & 3D Tilt**: Ultra-sleek frosted acrylic card with specular reflection and particle trail cursor.
- 🎧 **Built-in Music Player & Audio Visualizer**: Real-time frequency spectrum visualizer powered by Web Audio API.
- 💬 **Discord Sync (guns.lol & zyo.lol style)**: Connect Discord to automatically pull avatar, banner, badges, and live presence via Lanyard.
- 🔒 **Secured Config Modal**: In-bio live configuration panel protected by SHA-256 salted cryptographic hash. The password is never stored in plain text.
- 🌐 **Zero Dependencies**: Pure HTML5, CSS3, Vanilla JS. Hosted free on GitHub Pages.
